# 留页 · 全页面视觉设计

状态：设计准备已完成，尚未调用生图服务。

用户要求使用 GPT-image2.5。当前会话内置 image_gen 工具不暴露模型选择参数，不能指定或确认该型号；已向用户询问是否接受当前内置生图工具，或提供指定模型的服务方式。不得将其他模型输出标记为 GPT-image2.5。

## 最新成品要求

- 版式改为 ZPS 竖 12 寸、16P；准确宽高与封面计数等待确认，不沿用旧版 4:3 横向尺寸。
- 阅读增加纸页翻动效果、背景音乐与音乐开关；手机使用单页阅读，电脑可展示对页。
- 音乐在主动打开相册后尝试播放；不承诺未经交互的自动播放。
- 用户主动发布后生成可在手机访问的只读链接；草稿继续保存在本机。发布需要真实线上存储与服务，不用 localhost 链接冒充可分享链接。
- 官方内置生图说明当前标注 gpt-image-2；GPT Image 2.5 API 提供 sunburst / flare。尚未切换通道或调用 API。

## 制作方式

1. 先生成「模板与相册编辑」主界面设计图，建立统一视觉方向。
2. 用户确认使用可调用的生图方式后，每个页面或关键状态单独生成设计图。后续页面使用主界面设计图作为视觉参考。
3. 保存生成结果与完整提示词，记录实际工具及可确认的模型信息。
4. 按设计图实现可访问、可点击的 HTML/CSS/React 界面；设计图不作为整页背景替代真实控件。
5. 检查桌面、窄屏、加载、错误、禁用、空状态及键盘操作。保留现有上传、排版、保存、导出行为。

## 视觉约束

- 主题：旅行中的人物艺术写真；独立摄影出版物气质，照片是视觉中心。
- 色彩：雾白 #F5F6F3、墨灰 #292D2C、鼠尾草绿 #7D8C80、边线 #DDE1DB、辅助紫灰 #ADA5B7。
- 标题以中文宋体气质呈现，工具文字清晰易读。避免大段英文装饰、泛用科技渐变、发光效果、玻璃卡片。
- 统一纸页、留白、细线、按钮高度、图标笔画与间距系统；真实照片不加假滤镜。
- 纸张质感仅极轻微呈现，不能降低照片清晰度或文字对比度。
- 四模板：素笺 / 远行 / 片段 / 夜色。照片在画框中的选择与裁切由用户掌控。
- 示例照片只能作设计演示，不得暗示来自用户的真实旅行经历。
- 网站产品功能不加入 AI 识别、AI 文案或登录；用户主动发布时上传成品用于在线分享。生图只用于开发过程的 UI 设计。

## 交付检查

每张设计图必须有对应实现状态，不能只完成首屏。对照截图检查布局、排版、字体、间距和状态反馈；导入、手动封面、分组、删除撤销、取景、自动保存与三类导出都必须继续可用。
